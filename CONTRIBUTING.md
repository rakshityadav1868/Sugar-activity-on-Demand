# Contributing to Sugar Activity Studio

Thank you for helping make activity creation more accessible to learners and
teachers. The canonical contributor guide is maintained in the Fumadocs site:

- [Contributor guide](website/content/docs/contributing/index.mdx)
- [Development setup](website/content/docs/getting-started/development-setup.mdx)
- [Architecture](website/content/docs/architecture/index.mdx)
- [Testing](website/content/docs/contributing/testing.mdx)
- [Documentation workflow](website/content/docs/contributing/documentation.mdx)

For a local rendered copy:

```sh
cd website
npm install
npm run dev
```

Open <http://localhost:3000/docs>. Before opening a change, run the Python test
suite and documentation checks described in the contributor guide.
