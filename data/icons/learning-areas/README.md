# Sugar learning-area icons

These SVGs are verbatim copies from the official
[`sugarlabs/sugar-artwork`](https://github.com/sugarlabs/sugar-artwork)
repository at commit `3c4854d3eec0ba9b02a9ad139462fd559e6c027d`.

| Studio learning area | Sugar artwork source |
| --- | --- |
| Logic & math | `icons/scalable/actions/insert-table.svg` |
| Science | `icons/scalable/actions/system-search.svg` |
| Language | `icons/scalable/actions/edit-description.svg` |
| Tools | `icons/scalable/categories/preferences-system.svg` |
| Games | `icons/scalable/actions/media-playback-start.svg` |
| Creation | `icons/scalable/actions/toolbar-colors.svg` |

The upstream `LICENSE` and `COPYING` files are included beside the icons.

The `*-category.svg` files are original category-specific icons created for
the Studio after the upstream set was found not to contain a dedicated icon
set for these six learning areas. They follow the same Sugar conventions as
the referenced artwork: a 55×55 canvas, `stroke_color`/`fill_color` entities,
3.5px rounded strokes, and simple silhouettes that remain readable at toolbar
size. The verbatim upstream SVGs remain beside them as design references and
fallback assets.

The `*-color.svg` variants are the production prompt-screen artwork. They use
literal fills, dark outlines, and white or multicolor details to match the
approved prompt-control icons and remain vibrant under every desktop theme.
